# 金钱感悟文章写作

写普通人和钱的关系：月薪分几档、存款分几级、工资配什么车。文章的力量不来自道理，来自具体的数字、具体的人和最后那句收得住的判断。

## 定位与默认约定

- **默认交付一个 `.md` 文件**，正文用 Markdown 写。文章标题不写进文件——公众号编辑器里另有标题输入框，标题在回复里给。版式见 [交付格式](references/交付格式.md)。用户明确要 HTML 或纯文本时按要求给。
- **正文默认 1100—1500 字。**三篇例文都在这个区间。用户指定其他篇幅时以用户要求为准。
- **自称用“我”，一个普通打工人。**文章的可信度全靠这个身份：我经历过、我见过、我算过这笔账。不端专家架子，不装成功人士。例文里“往上多少我就够不着了，也不会装作知道”这种承认边界的话，是这个身份的一部分。
- **一篇只讲一个钱的话题。**月薪、存款、配车、房租、随礼，一篇一个，不拼盘。
- **基调是理解，不是审判。**写低收入不嘲讽（“这档人不缺力气，缺少的是向上迈出半步的机会”），写高收入不谄媚（“赚得多了也没有人帮你垫付”），写自己的选择不推给别人（“并不是说我买车就是错的”）。最后一定落到反焦虑上，这是这类文章的底线。

## 写作前

1. **用户给了话题就直接写**，不问要什么风格、给谁看、分几档。话题宽泛时（“写写钱”）自己收窄到一个具体切口（工资、存款、随礼、副业），按最贴近例文的处理。
2. 出稿前读 [例文拆解](references/例文拆解.md)（三篇例文各自的推进方式和语感）和 [交付格式](references/交付格式.md)（版式与字数）。
3. **用户给了真实经历和数字就优先用，不改用户的数。**用户说月供 3800、到手九千，就用这两个数往下算。用户只给话题时，人物和数字按「事实边界」一节处理。
4. 写之前先把整篇的账算一遍：分几档、每档的数是多少、合计对不对。这类文章全是数字，**一处算错整篇穿帮**。

## 标题

用户给标题就直接用，不给就拟一个。例文标题的路子：

```text
{男生}{月薪}的{几}个档次
{存款}的{五}个级别：第一级{敢生病}，最高级{敢转身}
你的{存款}到什么{等级}了
{买车}这件事上，最不应该去参考的是你的{工资}
你的{工资}该配什么{车}
```

要点：

- **标题里可以有分档数和判断句钩子**（“第一级敢生病，最高级敢转身”），钩子必须正文撑得住——正文没有“敢转身”那一层，标题就不许写。
- “你的……”式提问好用，但问题要具体（“到什么等级了”“该配什么车”），不用“你真的会花钱吗”这种空问。
- 不用“震惊”“扎心”“看哭”这类词，不用感叹号。

## 正文骨架

两种骨架，按选题选。各段预算是约数，最终以整篇计数为准。

### 骨架 A：分档盘点型

适合“月薪的几个档次”“存款的几个级别”这类选题。

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 120—180 | 一个带冲突的具体场景引出话题：烧烤摊上几个人争“月收入多少算合格”、群里为随 200 还是 600 吵了几十条。场景里有人、有争论、有数字。**不要静态的日记式开头**（“我翻备忘录发现……”）——争论把读者拽进来，“我”的记录和经历跟在后面出场 |
| 分档主体 | 700—1000 | 5—8 档，每档 100—150 字：一个人物 + 一个细节 + 一句引语 + 一句判断。写法见下。**分档逻辑要统一**：全按金额、全按关系或全按状态，不混着排；混不进去的单独开一组“例外”。档名小标题的格式是“金额或状态：这档的核心洞察”，洞察就是那句最狠的判断 |
| 收尾 | 120—180 | 把各档串成一句排比（“三千人愁没有选择，一万人愁……”），落到反焦虑的判断 |

每档的写法是这类文章的核心，四件套：

1. **人物**：用身份标签，不用名字。“去年带过的一个实习生”“小区门口便利店的店长”“一位做设计的朋友”。注意例文的讲法——每档都从“我”和这个人的关系进，“我”是见证者。
2. **细节**：一个具体的数或一个具体的画面。“每天要站十二个小时”“礼金给了两千”“投了二百多份简历”。
3. **引语**：让人物自己说一句。“我一个小时 18 元，一站一天也就这样了。”引语要笨、要短，是这个人真会说出来的话，不设计机锋。
4. **判断**：作者收一句，这句是档眼，但要“钝”不要“巧”。“贫穷的本质是没有选择”“这档人不缺力气，缺少的是向上迈出半步的机会”。平静的陈述，不是对仗的金句。

档与档之间可以用分组（“起点与台阶”“够花与不够花”）或判断句小标题隔开，见交付格式。

### 骨架 B：一笔账型

适合“工资配什么车”“月入多少该租什么房”这类消费决策选题。

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100—150 | 反常识结论前置（“买车这件事上，最不应该参考的是你的工资”），加一句自己交过的学费 |
| 一笔账 | 300—400 | 把自己当年那笔账摊开：明面的数（月供 3800）和背后的长尾巴（车位、油、保险、保养）。数字逐项列出，合计算对 |
| 方法 | 200—300 | 给一个笨办法、一个算法（“算全年，除十二”“存款 ÷ 每月固定开支 = 可以撑多久”），并给一条可执行的线（“超过每月结余一半就别买”） |
| 分层建议 | 200—300 | 按收入分 3 档给建议，每档两三句，语气是“说点实在的” |
| 收尾 | 100—150 | 落到物的本质：“车子是用来开的，不是用来证明自己的” |

要点：

- **账要真算。**例文里“月供 3800 + 车位 600 + 油 1500 + 保险 500 + 保养洗车违章 ≈ 6000 多”，加总是对的。写之前用实际数字验算，不能让读者抓到一个算错的地方。
- **方法是文章的干货**，读者收藏这篇就是为了这个算法。算法要简单到五个字能说完（“算全年，除十二”），线要画在读者能自己套的地方。
- 收尾承认反面的合理性（“有的人就爱车，为车牺牲别的也可以”），再落回自己的判断，不把选择推给读者。

## 语言规矩

这类文章最容易写岔成文案腔：金句密、对仗工、句句想抖包袱。例文不是这个声音。例文是讲述，不是表演。

- **“我”必须在场，但视角是群像，不是自传。**每档从“我”和这个人的关系进：“去年带过的一个实习生”“朋友的账单我已经看过”“前几天遇到了一个跑外卖的”。“我”是见证者，不是主角——通篇都是“我”自己的经历，文章就成了日记。例文写的是“我看到的别人”：实习生、店长、外卖员。每篇至少一两档的主角是别人，或加一两个旁观来的故事（借钱随礼的同事、为两百块礼金三年不说话的亲戚）。
- **判断收着用。**每档先把人和事讲清楚，判断最多一句，放在档尾。一篇里真正发光的句子三四句就够；句句都写成金句，读起来像文案，不像人话。
- **开篇不宣布论点。**例文开头给的是场景和一条认知弧线：“25 岁的时候我也有过这样的想法……后来见到的人越来越多才明白，并不是这样的。”过渡句是中性的——“下面这八档，就是这几年来我亲眼看到的一些事情”。**不在开头说“我看出门道了：X 讲的其实是 Y”**。论点一宣布，后面所有故事都降级成论据，文章只剩说明感，没有探索感。把结论留给读者自己走到。
- **故事要给代价。**一个人物的力度来自他付出的具体代价：到手六千、房租两千八、借完一千块接下来半个月午饭都是便利店饭团。只有对话没有代价，故事就轻，再多机锋也托不住。
- **档眼要狠，不要巧。**每档收一句硬判断，狠在观点本身——“贫穷的本质是没有选择”“每一元钱都有一个名字”。狠靠的是下断言，不是对仗和比喻：“红包里包的不是钱，是情谊”这种句子修辞很完整，观点却没下去，是巧不是狠。一档最多一句，放在档尾或进小标题。一篇里这种句子三四处，其余篇幅都在讲故事。
- **小标题混着写，不一档一个概念。**例文的小标题有命名（“每一元钱都有一个名字”），也有白描（“连门都进不了”“赚得多了也没有人帮你垫付”）。档档都是“X = 概念词”（社交保险费、活期存款、关系破产），就连成了 PPT 目录——单看都对，连起来读者能猜到全文。命名留给最痛的那两三档，其他档用陈述句和画面。
- **“不是……而是……”用来解释，不用来对仗。**例文的用法是带因果的长句：“最难过的并不是因为收入低，而是说不出来‘不想再做了’这几个字。”不是“A 不是 X，是 Y”的两个名词对撞。
- **句子可以长，多用“了”。**段落仍然短，但段内是带因果、带经过的讲述句，完成态的“了”用得很多：“熬过了转正”“早就算不清了”“年纪这一栏已经把门给关上了”。这个“了”是讲述感的来源，别为了脆而全删成短句。
- **引语要笨，放段尾，让它自己落地。**像那个人真的会说的话：“我一个小时可以得到 18 元，一站一天也就这样了。”不设计机锋，不押韵，不替人物总结。**引语后面不跟作者的评论**——人物说完，这段就收（“人家都随，我不随，以后还怎么处”后面再来一句“人情的利息就是这么还的”，就泄了）。一档只有一句判断的额度：引语扛住了，判断就省掉或挪到引语前面。
- **收尾：串档排比可以学，最后两句要具体，不落格言。**路子是：以前我认为……后来才知道……（排比把各档串一遍）……没有谁的更容易。但最后要落到具体的东西上——例文给的是“口袋里有钱可以花，身体没有严重的疾病，下班之后有一个热乎的饭菜吃”，是能摸着的画面，不是“别让礼单上的数替你决定谁重要”这种格言。“X 是给别人看的，日子是自己过的”是例文的句子，也不能换词照搬，一套模板，“AI 套壳感”就出来了。
- **数字必须具体。**不说“工资不高”，说“试用期 3500”；不说“没存下钱”，说“全年存款八千元”“答案是 37 天”。数字是这类文章的血肉。
- **口语，但干净。**可以用“说白了”“其实”“就是”，不用“家人们”“宝子”“绝绝子”。感叹号极少用，全篇不超过一处。
- **例文里有个别语病和改写痕迹**（“六五千块钱”“三万个个人”），那是例文的瑕疵，不要学，稿子要通顺。

## 改稿：润色递减律

同一篇稿子，**改到第二轮以后，不再润色字句**。不换标题、不换结尾、删一句补一句的抛光，只会把毛边和锐角一起磨掉——越改越工整，越工整越像“正确的模板文章”，离例文的声音越远。

第二轮以后还有问题，只有两种改法：

- **加新素材**：一个新人物、一个新场景、一笔具体的代价（工资、房租、借完钱怎么过日子）。力度永远来自新加的生活细节，不来自句子的重新排列。
- **加不出来就换题重写。**说明这个题材手里的素材撑不住，硬磨没有出路。

用户反馈里指哪句就改哪句，不顺手“优化”没被点到的地方——每次顺手优化，都是在给文章再打一层蜡。

## 事实边界

- **账要内部自洽。**收入、月供、各项开支、合计，全部验算。分层建议里的数也要自洽：说月入五千买三四万的二手车，后面的建议就不能和这条打架。
- **不编外部数据。**不引用“据统计”“研究表明”“专家说”，不编平均工资、收入分布这类可核查的数。文章的依据是“我见过”“我算过”，不是权威数据。
- **人物是典型化写作素材。**“一个实习生”“便利店店长”这类人物可以虚构，但细节要符合这个身份的常识（便利店店长轮班、站十二小时是合理的）。用户提供了真实人物和数字时，优先用用户的，不夸大。
- **不教理财，不荐产品。**不写“该买某基金/某股票”，不给投资建议。这类文章谈的是处境和心态，不是资产配置。
- **不制造焦虑。**可以写难处，但落脚点必须是“没有人比别人更容易”“不用按别人的地位生活”。写完自己读一遍：读者读完是松一口气，还是更慌？更慌就是写岔了。
- **不做人生导师。**“你该如何如何”的训诫腔不要，给建议时用“说点实在的”这种平视的姿态。

## 交付与计数

- **默认交付一个 `.md` 文件。**标题在回复里给，不写进文件。版式细节见 [交付格式](references/交付格式.md)。
- **字数口径：**Markdown 标记剥掉后的可见字符数，含标点、数字和英文字母，每个字符计 1；不计空格、换行等空白。标题、编辑说明不计入。
- 交稿前把正文存成 UTF-8 纯文本（不含标题和编辑说明），运行：

  ```bash
  python scripts/count_body.py <正文纯文本文件> --min-length 1100 --max-length 1500
  ```

  脚本相对本 skill 目录定位。用户另定篇幅时传对应区间。调整正文后重新计数。**超出区间先并档或删重复的例子，不删每档的判断句。**
- 交付时给：标题（一句）+ md 文件路径。账里的关键数字、和用户素材不一致的地方、需要用户拍板的地方，用一两句话单独说明，不铺成章节。

## 交付前检查

- 标题里的分档数和钩子，正文都撑得住。
- 全篇的账验算过一遍：每档的数、合计、算法示例，都对得上。
- 每档四件套齐全：人物、细节、引语、判断。至少一两档的主角是别人，不是通篇“我”的经历。
- **开头是带冲突的线下场景**（聚餐、烧烤摊、茶水间，有声音有身体感），不是群聊截图式的扁冲突，更不是日记式自述。
- **开头没有宣布论点**——过渡是“下面这几档，是我一笔一笔随出来的”这种中性句，结论留给读者。
- 分档逻辑统一（全按金额或全按关系），混不进去的归到例外组；**小标题命名和白描混着用**，没有档档都是“X = 概念词”。
- **主要人物给了具体代价**（工资、房租、借完钱怎么过日子），不是只有对话。
- 每档档眼是硬断言，不是修辞游戏；通读一遍，把对仗工整、像文案的句子改掉；一篇发光的句子不超过三四处。
- **引语后面没有跟总结**——人物说完话，那段就收住了。
- 感叹号不超过一处，没有“震惊”“扎心”这类词。
- 收尾的串档排比在，最后两句是具体画面不是格言，没有换词套例文的“X 是给别人看的”。
- 组名有意象（“起点与台阶”“账外”），不是“四种关系”这种提纲标签。
- 没有“据统计”“研究表明”“专家说”这类无出处背书，没有理财建议。
- 收尾落在反焦虑上，读完是松一口气，不是更慌。
- 没有例文那种语病；通读一遍，每句都通顺。
- Markdown 按 [交付格式](references/交付格式.md) 的自检清单过一遍。
