# 数据核查范例

核查日期：2026-09-18。本文用于示范如何核对和限定主张，不是可以直接复制的数字库。每次写作仍须检查来源是否支持当前这句话，以及有无勘误、撤稿或指南更新。旧稿、转述文章和本文件都不能替代原始证据。

## 一、先给主张分类型，再找来源

| 主张类型 | 优先依据 | 必须核对 |
| :--- | :--- | :--- |
| 论文效应：某食物与某结果有关，或干预后某指标变化 | 原始论文的方法、结果及对应表图；概括总体证据时查系统综述及其纳入研究 | 设计、人群、样本、对照、干预条件、随访、效应指标、区间及局限 |
| 指南推荐：一天吃多少、何时就医、哪些人不适用 | 发布机构的现行指南、正式共识或官方原文 | 版本、适用人群、推荐强度、原文位置；不能把推荐量写成疗效阈值 |
| 成分数据：每 100 克含多少、不同油脂比例 | 权威食物成分数据库、官方成分表或可追溯检测 | 数据库版本、食品条目编号、生熟状态、可食部、计量单位和分母 |
| 机制解释：某成分如何作用 | 实际支持该机制的研究或权威综述 | 是人体、动物还是体外证据；剂量和条件；是否仅为假说 |

给每条来源编号，如 `[1]`、`[2]`。论文编号、指南版本、数据库食品编号各有用途，不能用一个“研究指出”混在一起。机构新闻稿和搜索摘要可帮助定位，不能替代缺失的方法和结果；只读到摘要就如实标为“仅核摘要”。

建议在写稿前保留以下核查记录，正文中的关键主张与来源编号对应：

```text
[编号] 主张类型：论文效应 / 指南推荐 / 成分数据 / 机制
拟写主张：
来源：作者或机构、标题、期刊或版本、发表日期
定位：原文链接；DOI / PMID / 食品条目编号（适用时）；章节 / 页码 / 表图
适用对象：人群、样本或具体食品；不能适用的情形
设计与条件：对照、剂量、期限；或指南适用范围、成分计量口径
结果：指标、效应值、区间、比较对象（不适用则注明）
局限：混杂、偏倚、失访、外推限制；机制与疗效的区别
核查状态：已读支持该主张的原文段落 / 仅核摘要 / 待核查
核查日期；允许写法：
```

## 二、三个论文教学案例

### [1] 苹果与心血管死亡：模型预测不是临床效果

- **来源与定位：**Briggs 等，*BMJ*，2013，347:f7267；[论文 PDF](https://www.bmj.com/content/bmj/347/bmj.f7267.full.pdf)，[PMC 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3898162/)；DOI：10.1136/bmj.f7267。查看摘要、Methods、Results 及 Discussion。
- **人群、设计与条件：**英国 50 岁以上成人的数学模型；每日一个 100 克苹果，假设依从率 70%、总热量不变。
- **结果与局限：**模型估计每年可少发生约 8500 例血管性死亡，95% 可信区间 6200—10800。依赖模型假设，并非实际给人吃苹果后观察到的死亡减少，也未证明可替代他汀。
- **允许写法：**“一项英国模型研究估计，在特定假设下，增加苹果摄入可能减少人群中的血管性死亡。”引用数字时保留条件，不转成个人疗效或停药建议。
- **核查状态：**已核原文索引中的方法及期刊 PDF 摘要内容；PMC 页面直开曾触发验证码。

### [2] 高血压与苹果：相关性不等于最佳吃法

- **来源与定位：**Sun 等，*Frontiers in Nutrition*，[期刊原文](https://www.frontiersin.org/journals/nutrition/articles/10.3389/fnut.2024.1461196/full)；DOI：10.3389/fnut.2024.1461196。发表于 **2025-01-24**，归入 2024 年卷；查看 Methods、Table 2 的 Model 3 和 Discussion。
- **人群、设计与条件：**2368 名美国高血压参与者，饮食频率问卷结合死亡随访的观察性分析。相比不吃苹果，每周 3—6 次组的全因死亡 HR 为 0.52，95% CI 0.37—0.72。
- **局限与允许写法：**“该摄入频率与较低全因死亡风险相关”，不能写成保证降低死亡风险的处方；存在自报误差和混杂。频率不提供每次克数、个数或是否带皮，不能据此拼出“每次一个带皮苹果”的最佳剂量。果汁、苹果酱结果未达统计学显著，不等于证明无效或有害。
- **核查状态：**已读期刊方法、结果及局限。

### [3] 花生与减重：保留对照组和整个饮食方案

- **来源与定位：**Petersen 等，*Nutrients*，2022，14(14):2986；[PMC 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9318508/)；DOI：10.3390/nu14142986。查看 2.1—2.3、3.1—3.3 和 Discussion。
- **人群与条件：**澳大利亚超重或肥胖、2 型糖尿病中高风险成人，107 人随机分组，76 人完成。两组均限能量并接受营养指导；花生组每日 70 克花生，对照组采用低脂饮食。不能把两组都称为低脂餐，也不能将参与者统称糖尿病患者。
- **结果：**6 个月减重分别为 6.72 和 6.60 千克；组间差 −0.12 千克，95% CI −2.42—2.18，未发现额外减重优势。收缩压差异是另一个结果，不等于已证实减少心血管事件。
- **允许写法与局限：**“在限能量饮食中，两组减重幅度相近。”不能把全部减重归功于花生，也不能断言花生完全无关。样本小且有失访，试验用量不直接变成大众推荐量。
- **核查状态：**已核 PMC 原文索引中的方法、结果及局限；页面直开曾触发验证码。

## 三、指南推荐示例

### [4] 添加糖：完整保留推荐口径

- **来源与定位：**中国营养学会，[《中国居民膳食指南（2022）》核心推荐](https://www.cnsoc.org/bookpublica/0522202019.html)，2022-07-01；“准则五：少盐少油，控糖限酒”。官方指南介绍，无 DOI。
- **原意：**控制添加糖，日摄入不超过 50 克，最好低于 25 克。这是一般膳食推荐，不是某项试验发现的疗效剂量，也不是所有糖类合计的限量。
- **适用与限制：**面向一般居民的膳食建议；具体疾病、特殊人群的安排另查相应指南。不把“最好控制”改写为单一绝对上限。
- **核查状态：**已读发布机构核心推荐；实际用稿前检查是否已有新版。

## 四、每篇稿子的核查步骤

1. **列出需要证据的句子。**包括标题中的数字、比较、疗效、见效时间、机制和建议量；小标题、图注也算。
2. **按第一节选择证据。**从转述追到原文；记录实际读到的内容，不把找到 DOI 等同于已核实结论。内容涉及医疗建议时核对现行权威来源。
3. **核对设计与质量。**随机试验也可能样本小、失访多、存在偏倚；观察研究即使调整了混杂也不能自动视为因果。不能只按设计名称机械排序。
4. **核对比较和单位。**看对照组、基线、组间差、绝对量与相对量；区分 HR、RR、OR 与绝对风险。营养数据先统一可食部、生熟状态、份量和分母再比较。
5. **核对不确定性。**保留原文区间及其类型，不自行拼区间；未达显著不证明等效、无效或无关联，显著也不等于效果对个人重要。
6. **核对推论边界。**研究随访期不是见效期限；一次研究的摄入分组不是最佳剂量；血压、血脂变化不是寿命或死亡率的直接证据；机制证据不自动支持人体疗效。
7. **将主张逐句对回来源。**数值要有条件，限制要靠近结论。文章参考来源用编号链接对应，并写清版本或年份；无法支持的句子删掉或收窄。

## 五、来源不足时怎么处理

- **标题与正文同一标准。**核不出的倍数、排名、百分比和疗效不用于标题，不能用正文“未找到出处”来补救标题断言。
- 机制同样需要来源。可解释研究提出的假说并标明“可能”，不能凭合理想象写成确定的作用链，也不能用比喻补齐未知机制。
- 联网不可用、原文打不开或关键方法缺失时，明确记录核查局限。删除无法核实的数字及其衍生结论；内部稿可标“待核查”，不作为已核实内容交付。若该主张决定文章核心结论，先说明证据不足，不凑齐模板。
- 找到摘要只能使用其明确支持的有限信息，不补全未见的剂量、分组、疗程、机制或不良反应。论文正文引用另一项研究时，关键结论继续追到被引用研究。

旧版“可以放心用的底数”已取消。以下只保留检索任务，不保留容易被照搬的精确数字：

| 线索 | 缺什么；如何处理 |
| :--- | :--- |
| 猪油、动物油与中国老年人心血管疾病；曾指向 CLHLS 和 *Current Problems in Cardiology* | 尚未定位并核对原论文、DOI、设计、样本及表格，不标“真实”或“已核实”；不引用原稿风险比例，不据此推荐猪油 |
| 猪油脂肪酸构成、猪大肠营养及嘌呤含量 | 缺可定位数据库版本、食品编号及生熟口径；重新查成分表，不能混用不同来源或分母 |
| 花生的升糖指数、每日克数与颗粒数换算 | 缺具体食品测试和推荐来源；GI、指南推荐量和按粒估算分开核查 |
| 饮酒量与甘油三酯变化或高甘油三酯比例 | 缺原研究、单位、人群及比较条件；不能复用旧稿精确效应 |
| 花生与端粒、坚果与糖尿病患者体重的综述 | 缺原论文及研究设计、纳入项数和样本核对；不得以“延长端粒”推导延寿 |

新增核实资料时，按第一节的来源卡补齐信息并注明核查范围。不要重新建立脱离出处和条件的“万能底数”。
