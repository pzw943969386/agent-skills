# 标题公式

## 一、四段式拆解

`人群锁定 + 情绪/利益钩子 + 数字或利益点 + 互动式提问`

用作者自己的 6 个标题逐段拆：

## 二、各段词库

### 人群词（置首）
企业退休 / 退休人员 / 灵活就业者 / 灵活就业 / 城乡居民 / 机关事业单位 / 在职职工 / 退休老人 / 60后、70后 / 即将退休的人

### 情绪钩子（带感叹号）
`注意了！` `注意！` `有福了！` `好消息！` `传来数据` `定了！` `明确了！` `传来新消息` `终于等到` `别再忽视了` `要留意了` `这下清楚了`

### 利益点
这几档 / 这几笔补贴 / 这几项待遇 / 这几个变化 / 这几方面 / 这笔钱 / 人均水平 / 新规

### 互动提问（收尾）
`看看你在哪一档次？` `看看你能领取多少？` `看看你符合条件吗？` `来了解一下` `你都了解了吗？` `一文读懂` `别错过了`

### 情绪共鸣型（不用感叹号，用反差对仗）
`年轻时……，老了……，心愿心酸又真实`
`交了一辈子社保，退休能拿多少？`
`同样是退休，为什么差距这么大？`

## 三、可直接套用的标题骨架

**分档/对比类**
1. [人群]注意了！你的养老金分为这几档，看看你在哪一档次？
2. 同样是[人群]，为什么有人拿[高值]，有人只拿[低值]？
3. [人群]养老金差距有多大？这[N]个档次，对号入座看看
4. 你的养老金处在什么水平？一组数据告诉你答案

**补贴/待遇类**
5. [人群]有福了！这几笔补贴人人都有份，看看你能领取多少？
6. 除了养老金，[人群]还能领这几笔钱，很多人不知道
7. [人群]这几项待遇别错过，错过就亏了
8. 这笔钱[人群]都能领，但需要你主动申请

**政策解读类**
9. [人群]好消息！今后[政策变化]，让更多人享受[福利]
10. [部门]传来数据，[指标]标准出炉，来了解一下
11. [新规]落地，对[人群]有什么影响？这几点要看清
12. [人群]注意！[时间点]起，这件事要这么办了

**认知纠偏类**
13. [人群]注意！[做某事]究竟划算不划算？这几方面你都了解了吗？
14. 不缴社保真的划算吗？看完这笔账你就明白了
15. 很多人以为[错误认知]，其实[正确认知]
16. [人群]最容易踩的[N]个坑，别等吃亏才知道

**情绪共鸣类**
17. 年轻时拼命工作，老了体面养老，[N]亿[人群]心愿心酸又真实
18. 交了[N]年社保，退休第一天拿到这个数，心里五味杂陈
19. [人群]的真实养老生活，比想象中更为现实
20. 为什么[人群]的养老金上不去？原因其实就这几点

## 四、标题避坑

- ❌ 标题党过度（"震惊""速看""紧急通知"）—— 作者的钩子克制，只有"注意了/好消息/有福了"这几种
- ❌ 全标题不超过 30 字，太长会被截断
- ❌ 不用书名号、不用问号堆叠两个以上
- ✅ 每段标题里尽量带一个具体数字（1.5亿 / 3300元 / 4个档次 / 7000万）
- ✅ "看看你能领多少" 这类**对号入座式**提问是本文风招牌，多用
