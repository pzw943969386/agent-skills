# 语言特征

从 7 篇历史原文提炼表达方式。**学亲近、连贯和结论前置，不照搬医学断言、作者身份或失当标点。**下列长度、数量和句式是风格偏好；准确、清楚和适合当前选题优先。

## 一、一段一个气口

作者常把“前提—转折—结果—补充”用逗号串起来，读起来像面对面讲解。

- **段末逗号可以保留。**它是这类稿子的口语节奏，用一个逗号把话交给下一段，读者会跟着往下读。但要和句号分工：交代条件、陈列情形、铺场景的句子可以用逗号收；**下判断的那一句用句号截断**。两种收尾都要有，整篇全是逗号会让人觉得话没说完。
- **段落要短。**一段讲清一件事，通常 30—80 字，**超过 100 字就拆**。拆的位置通常在“证据说完”和“所以呢”之间。
- **长短段交替。**一两个长段（80—100 字，把证据、条件、出处交代清楚）后面跟一个短段（10—30 字，把判断收住）。整篇都是长段，读者会累；整篇都是短段，像喊口号。
- **长短句也交替。**段落长不等于句子长。一段里连着几句都是逗号串起来的长句时，把结论那一句单独成句，用句号截断。
- 句子出现多层条件、多个结论时，拆开更清楚。
- 句意完整就用句号，并列项按需要用顿号或分号。
- 医学限制条件应贴着结论写，不要藏在下一段或文末。

交稿前数一遍各段字数，把超过 100 字的段落拆开。拆完再读一遍：长段之间有没有短段换气。

示例：

> 先看研究比较了什么。两组人都改善了，不等于其中一种食物带来了额外好处，还要看两组之间有没有可靠差异。

## 二、金句和加粗重点

短句用于收住论点，不必每段都有。每篇可放 1—3 处，也可以不用；篇幅和信息量决定数量。

**默认用加粗重点分段，也可以用判断句小标题。**把一段里最要紧的判断加粗成一句，放在段首或段中，读者扫一眼就能接住这段在讲什么。加粗的是结论本身，不是“第一点”“原因有两个”这类标签，也不编号、不加冒号。小标题、红色、下划线加起来一篇不超过十处；到处都是强调，等于没有强调。三种标记的分工与样式见 `公众号HTML排版.md` 第一节。

篇幅偏长、或几段之间是并列判断时，可以用小标题，但小标题本身得是一句结论（“两顿饭与死亡风险的关联确实存在”“相关不等于因果”“真正影响寿命的是节奏”），而不是话题名（“关于进食频率”“研究进展”）。

- 用了小标题，就不在段内重复加粗同一句。
- 编号式标签（“一、”“第二点”）任何时候都不写。
- 小标题和正文执行同一证据标准：**小标题里出现断言、数字或“确实”“真正”这类强调词，正文必须撑得住。**撑不住就把它降级成加粗的疑问句。

加粗句和下面说的金句是一回事，只是位置不同：金句独立成段，加粗句嵌在段落里承担分段的作用。

适合借鉴的表达示例：

- 吃了什么要看，替掉了什么也要看。
- 一项研究给了线索，不等于每个人都有同样结果。
- 数字要连着条件看。
- 馋的有时不是食材本身，而是那一口味道。

可以用对比、设问或生活化比喻，但不能为了有力而省掉决定结论的条件。不要把“某个症状就是某器官在求救”当成确定诊断，也不承诺坚持多久就能换来某种结果。

更值得学的是**把判断压缩成一句话**，而不是把话说得漂亮。三种结构：

| 结构 | 例子 | 好在哪 |
| :--- | :--- | :--- |
| 对比式 | 甜玉米是甜在嘴里，糯玉米是甜在血里。 | 两类的差别压成一句对仗；前提是正文已给出各自数值 |
| 正名式 | 玉米照吃、米饭照盛，那叫加餐，不叫替代。 | 用一个否定把替换关系说清，比“要注意替换主食”可执行 |
| 反问收束 | 别问玉米能不能吃，先问你是谁、吃的是哪种、怎么吃的。 | 把整篇的分层逻辑收成一句，适合放结尾 |

三种都以正文里的证据为前提。数值和人群条件没交代清楚时，这类句子会变成没有地基的口号。

### 纠偏句式：不是 A，是 B

这是这类稿子推进论证最常用的句式，可以承担整段的骨架，不只是收句。它干的事是**把读者认错的变量换回来**：

| 变体 | 例 |
| :--- | :--- |
| 不是 A，是 B | 这不是轻断食，这是没空吃 |
| 不在于 A，而在于 B | 问题不在于吃几顿，而在于你少吃的那顿饭，究竟少的是什么 |
| A 是框架，B 才是内容 | 进食频率是框架，食物质量才是内容 |
| A 的价值可能不在于 X，而在于 Y | 一天三顿的价值，可能不在于三这个数字，而在于它天然契合了…… |

- **一篇两到四处，各管一段。**开篇用一次定调，中段用一次纠偏，结尾用一次收束。
- **A 必须是读者真会认错的那个变量**，不是随手立的靶子。落笔前先想清楚：读者以为起作用的是哪个量，实际起作用的是哪个。
- **B 那一半要有正文撑。**“这不是轻断食，是没空吃”得靠后文交代两顿饭的都是些什么人；只给反转不给 B 的证据，就成了抖机灵。
- 同一篇里不要连着两段都用，会显出套路。

## 三、术语紧跟大白话

术语首次出现时给简短解释，后文用读者能理解的称呼。解释保持原意，不把复杂病理压缩成貌似直观、实际错误的一条因果链。

| 术语 | 可参考的解释方式 |
| :--- | :--- |
| 观察性研究 | 观察不同人群之间的差异，不能单靠它认定谁导致了谁 |
| 随机对照试验 | 通过随机分组比较不同安排的结果，还要看具体研究条件 |
| 对照组 | 用来比较的那一组，判断效果时不能只看干预组自身的变化 |
| 相对风险 | 与比较对象相比的风险大小，还要结合原本风险理解 |

通常按“读者的问题 → 必要术语或指标 → 证据能说明什么 → 生活中的含义”推进。不需要解释机制时可以省略；没有证据时不能补一个“听着合理”的机制。

## 四、设问推进

用设问换气，比机械的过渡词自然。设问本身也不能预设未被证实的结论。

- 这说明什么？
- 为什么是这个量？
- 那到底还能不能吃？
- 研究里比较的是哪些人？
- 是这组人有变化，还是它比对照组改善得更多？

## 五、结论先说，语气与证据匹配

开篇尽早回答核心问题，再解释依据和条件。明确不等于绝对，证据有限时也可以把话说清楚。

开篇还有一条路：**先给处境，再给结论。**把一个被当成“个人选择”的行为还原成处境——“你每天吃几顿饭，可能根本不是你自己的选择，工作忙到下午三点才吃第一口”，读者先认出自己，再愿意听后面的结论。接着把两边的说法都摆出来（一边说一天两顿更长寿，一边说少吃一顿折寿），必要时交代一句“今天不站队”，再往下拆。处境要来自读者真实的生活，不编造病例和对话。

- 可以说：“这项研究不能支持这个说法。”
- 可以说：“目前还不能据此判断有没有额外好处。”
- 核实确实存在误读时，可以直接指出哪里读错了。
- 不为强化语气反复写“大错特错”“从根上就是错的”。
- 不把“没有证实有效”改写成“证实完全无效”，也不把“未发现组间差异”改写成“与它毫无关系”。

**先站在读者这一边。**开篇和转折处先把读者的处境或困惑说出来，作者才有发言的位置。两种做法，可以合用：

- 替读者开脱：“你每天吃几顿饭，可能根本不是你自己的选择。”——把读者从“做错事的人”变成“有难处的人”。
- 替读者说出困惑：“两边都在说话，你却越听越不知道该信谁。”——先承认读者被绕晕了，再往下拆。

**给证据贴一个态度标签。**引用研究的前后，用一个小词告诉读者该往哪个方向理解：“这组数据常被解读为铁证”“一项更值得深思的研究”“一个有意思的参考值”“还有一个被忽视的变量”“结论出人意料”。标签只表态度，不表结论——“更值得深思”可以，“已经证实”不行；标签也不能代替正文对研究条件的交代。

**“可能”用来软化推测和评价，不用来软化数字。**“可能并没有想象中那么友好”“可能不在于三这个数字”“可能根本不是你自己的选择”，软化的本来就不是数据。反过来说，“或许会增加死亡风险”“可能让寿命缩短”是把没有依据的断言包起来，属于禁用。

## 六、人称与场景

- **默认身份**：普通科普作者。可以直接写“你”“很多读者”“有些朋友”，不默认具备医生或营养师资格。
- **第一人称**：可以用于本次确实做过的工作，如“我核对了这项研究”。没有实际检索时，不写“我翻遍了研究”。
- **接诊、回信、患者群和后台留言**：只用用户提供的真实素材，不编造“门诊里有位患者”“后台好几个人问我”。身份和署名也由用户提供，不能沿用范文作者的名号。
- **假设场景**：可以写“比如，有人早餐习惯……”“假设你平时……”，让读者清楚这是举例。不要添加诊断、检查结果和对话，伪装成真实病例。
- **读者称呼**：亲近且尊重。涉及疾病时先准确说明适用人群，再按上下文使用简短称呼。

## 七、比喻要帮读者理解

比喻落在日常生活上，点到为止。例如：“一项研究像一块拼图，还要和其他证据放在一起看。”

不使用“清理血管”“给心脏踩刹车”等容易被理解成生理事实的表达来承载结论。引用真实传言时应标明归属并及时澄清。比喻不能代替机制证据，也不能暗示食物与药物疗效相同。

## 八、标点与用词

- 以中文规范标点为主，感叹号、破折号按需要少量使用，不设机械禁令。
- 引号可用于真实引文、术语或需要澄清的说法。引用必须准确，不虚构引语。
- 少用“综上所述”“在当今社会”“随着生活水平提高”等空泛套话。
- 不必强行玩梗，也不必为了口语感故意写错标点。
- **并列成分也可以用逗号串起来。**“优质蛋白，足量蔬菜，适量粗粮”“调控着激素分泌，血糖代谢，细胞修复”——一口气说完是这套稿子的语气。可以用，但同一处并列不要逗号和顿号混着用，一段里最多一处，多了会读成断句错误。
- 链接、单位、研究名和必要英文按原有规范保留。

## 九、时间与量词

- 研究年份、随访时长、干预量照核实后的来源写；不为显得专业而添数字。
- 区分研究观察时间和个人见效时间，不能把前者改写成后者。
- 具体用量说明对象及口径，如每天还是每次、可食部还是带壳重量；必要时交代烹调方式。
- 日常参照只帮助估量，不能伪装成精确换算。不同大小的“一把”“一汤匙”没有统一重量。
- 数字通常用阿拉伯数字；口语短语可用中文数词。
- **效应量给完，接一句人话。**风险比或百分比后面，用一句话说明它在人的尺度上是什么量级：“数字看着不大，放在人群层面就不是小数点后的差别”，或者“这个量级小到日常很难感知”。这是帮读者掂量轻重，不是换算——不能凭空推成具体的死亡人数、寿命年数或“多少条生命”。条件是前提，人话是补充，顺序不能反。

## 十、人群怎么分层写

分层型选题里，“你是谁”是一个和食材、做法并列的变量。写的时候守住三条：

**分层维度要有出处。**用证据或指南里真实存在的适用差异——是否确诊糖尿病、有没有用药、年龄与咀嚼吞咽能力、肾功能。这些是可以判断、可以核对的。用没法核实的体质分类去分层，读者无从对号入座，也没法验证。

**每层单独给量，不给通用量。**同一个食物在不同层里的结论可以相反，这是分层型的价值所在。所有层共用一句“适量吃”，等于没分层。

**替换关系要说透。**把“替代”还是“额外添加”讲清楚：吃了这个，那顿饭的什么要减掉。只讲吃什么、不讲减什么，读者按最容易的方式理解，就等于加餐。

层的顺序按“离读者最近”排：先写人数最多、顾虑最轻的，再写最需要提醒的，最后写容易被忽略的（如牙口不好、消化弱的人）。每层收一句可以带走的话，结尾再按层各收一句。

## 十一、结尾提示

结尾可以先落回长期习惯，再给科普提示。行动建议之后抬一层、收到读者自己的处境上，是这类稿子常用的收法：

> 真正拉开人与人之间健康差距的，是你能不能长期吃够营养。
>
> 与其纠结少吃了哪一顿，不如想想，你吃进去的每一口，是在滋养身体，还是在应付生活。

这一层要用正文的证据垫着：前面讲了频率、节奏、食物质量，这里才能把它们收成一句长期习惯。**抬这一层不能顶掉免责声明。**上面那类句子后面，仍然要接：

默认保留简短科普提示：

> 本文仅作健康科普，不能替代个体诊疗；身体不适请及时就医。

涉及用药时，根据内容补充：

> 不要根据本文自行停药或调整剂量，用药问题请咨询医生或药师。

免责声明不能补救错误建议。若正文涉及就医时机，应依据具体症状和可靠来源说明，不统一套用“先观察两周”。
