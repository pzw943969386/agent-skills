# 骨架拆解

每篇一张骨架，帮助选结构。拆解不能代替原文，动笔前仍要完整读原文。

## 共同点

题材集中在月薪、年薪、家庭收入、存款、买车。标题短，用“你的”“男生”“普通家庭”圈定读者，用“等级”“档次”“段位”“配得上”让人想对照自己。

叙述者是一个普通上班族，第一人称，经历过比较、吃过亏。正文从一个具体场景进入，摊账，写代价，拿身边人对照，最后把“等级”重新解释成“过得踏不踏实、有没有选择”，结尾温情、直接，多数带一句评论区提问。

## 收入

### 《男生月薪的几个档次》（分档篇，八档）

烧烤摊同事争论“男性月收入多少算合格” → “25岁的时候我也有过这样的想法” → 八档，每档一个小标题，标题里就带判断（“3000元以下：贫穷的本质是没有选择”“一万元二到两万元：每一元钱都有一个名字”）→ 每档一个人一件事一句话，后接一句判断 → “最后”：把各档的“愁”排成一句 → 结尾“口袋里有钱可以花，身体没有严重的疾病，下班之后有一个热乎的饭菜吃，你就已经战胜了很多的人了”。

### 《七级月薪，七种活法》（分档篇，无人物）

直接列“第七级：3000元”到“第一级：50000元”，每档两三句，写花钱的动作（加不加蛋、外卖能不能选想吃的）→ “看完了，是不是有点想笑，又有点笑不出来？”→ 低薪烦恼具体、高薪烦恼在时间和健康 → 两点建议（不拿别人的标准、重新定义财富）→ 点赞收藏加评论区“你在哪一级”。素材少时用这篇的写法。

### 《中国普通家庭的月收入等级》（倒序分档）

搬家师傅猜“一个月怎么着也得一万五”，“我没有勇气接上话来” → 师傅自己的收入 → 引一两个统计数据 → “我们一般会往上看，今天就反过来数一数” → 两万（前同事住行军床、胃溃疡）、一万出头（自己涨薪后房租也涨，存款没变）、五千（表嫂当护工）→ “三十多岁，工作稳定，月薪一万……真的不算差” → 以前和自己较劲，后来明白 → 生活条件清单加“这就已经很不错了” → 评论区提问。

注意：标题说家庭收入，正文写的是个人工资；仿写时口径要对上。用到统计数据必须先核实。

### 《你的年薪属于什么级别》（编号论证篇）

青岛海鲜馆同学聚会，有人说三十万只够过日子，“我”拿着茶没搭话，因为下午刚面试完 → 一、招二十万的岗位收到三百多份简历：网上晒的是幸存者 → 二、“这张表格我也相信过”，涨薪当晚钱被家里开支转走：年薪是家庭的账单 → 三、五十多万的医药销售熬夜体检出问题，十来万的同事准点下班做饭 → 四、“所谓的年薪级别标准并不存在” → 结尾回扣那个同事的晚饭。

### 《你的月薪达到城市中位数了吗》（口吻例外）

妈妈以为在广州一个月赚两万，得知真相后在电话里问“你这些年是怎么活下来的” → 网上的年薪百万 → 驿站老板娘、外卖小哥 → 平均数与中位数 → 回老家，表妹和同桌说“你出息了” → “同一个数字，放在广州是焦虑，放在老家是羡慕” → 结尾肯定一个人在城市立住已经不容易。

这篇后半部分是短句碎行的写法，和其他九篇口吻不同。可以学它的结构，不学它的句子节奏。

## 存款

### 《你的存款达到多少级了》（另一篇近重复，读一篇即可）

发薪晚六天，信用卡还款日在第五天，每天查余额二十多次 → 算出不上班能撑37天，“在电脑前面坐了很长时间” → “真正的等级并不是金钱来衡量的，而是在于你能做些什么事情” → 小节：妈妈退回520又转来两千、第一笔钱是省出来的、老陈用贴纸遮住撞凹的车门 → 存款÷每月固定开支=能撑多久，按“撑不过一个月／三个月／半年／一年／两年”分级，每级一句“敢做什么” → 攒够一年后带父母去北京，点菜第一次没先看价格 → 不要按别人的地位生活 → “困难的时候能够挺身而出，不想忍耐的时候可以转过身去——这样就很好了”。

可以学“把金额折成能撑多久”“等级就是敢做什么”的写法，不要把37天、北京旅行原样搬过去。

## 车

### 《你的工资该配什么车》（观点先行）

“买车这件事情上，最不应该去参考的是你的工资” → 二十六岁月薪九千买二十多万的车，只算了月供 → 月供、车位、油、保险逐项列，一个月六千多，“我到手九千” → 妈妈住院卡里只有两千，向朋友借钱，一年半后卖车亏三万 → 换个问法：扣掉必要开支每月还剩多少 → 笨办法“算全年，除十二” → 网约车司机卖车的故事 → 按月收入五千、一万、两万各给一句建议 → 现在骑电动车加租车 → “买得到，养着也不觉得累，开着出去也不会感到害怕——这样的车，才配得上你”。

### 《哪款车配得上你的月薪》（人物前后照应）

“你自己算过自己开的一辆车一年要花多少钱吗？我没算过。” → 车库里老张蒙着车衣的三十多万的车，“油钱先缓一缓” → 回想自己月薪七千贷款买十五万的车，摊一年两万的账 → 推掉滑雪、给妈妈转钱后整月带饭 → 组里小伙子相亲后买车，吃最便宜的套餐 → “别人看你的车是什么牌子的时间加起来不会超过三秒钟” → 老张卖车，我也卖车改地铁加租车 → 父亲住院押金两万当场刷了 → “车是用来开的，并不是用来供奉的” → 评论区算一算。

老张开头出现，后面又回来收尾，人物不是用完就丢。

### 《男生买车的段位》（段位篇）

卖车时买主问为什么舍得卖，“我说不能加油了”，其实是假话 → 倒叙三年前跑业务觉得少一辆车，贷款买二十多万的车，摊三万六的账，花呗、三百多元的项链、女朋友说“你活得很累” → 九哥的皮卡（用途）→ 医院师兄的老卡罗拉（算账）→ 包工头老徐卖了宝马找他做事的人没少（人）→ “当年贷款买车的那个我，并不笨” → 生活条件加“比开着什么车都要体面” → 最后一句才命名：“从行头，工具，账到人，就是男人买车的四个段位。”

## 关于例文里的账

例文里有几处账算错了（比如每天四十单、每单五元、跑三十天是六千元，原文却写成七八千元），新写的文章要把账算对。算对账不影响口吻，其余写法照例文学。
