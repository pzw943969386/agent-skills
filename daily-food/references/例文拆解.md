# 例文拆解

来源：`例文/` 目录下 4 篇家常菜公众号文章（用户提供，2026-09-21 读取）。原文用于分析写法，**其中的家庭场景、配方来历和用量数字都不是可以直接搬进新文章的内容**。

## 一、共有的骨架

四篇的结构几乎一模一样：

| 段落 | 内容 | 篇幅 |
| :--- | :--- | :--- |
| 开篇 | 俗语、节日、季节或生活场景切入，引到这道菜 | 1—3 短段 |
| 过渡 | “今天就把做法分享给大家”“跟着步骤来，新手也能搞定” | 1 句 |
| 菜名 | 单独一行，常配 ❤️ 装饰 | 1 行 |
| 食材清单 | 一行列完，前加“食材准备：”“所需食材：”“【食材清单】” | 1 行 |
| 步骤 | 编号 1、2、3，**每步带“为什么”** | 2—8 步 |
| 收尾 | 复述口感 + 一句号召 | 1 段 |

这个骨架可以直接沿用，**开篇和收尾要换写法**——例文的这两处全靠家庭场景撑着，去掉家里人之后必须另找由头。

## 二、最值得学的一条：每步都带“为什么”

这是四篇里唯一称得上“技巧”的东西，也是它们区别于纯菜谱的地方。对照：

| 篇目 | 原文写法 |
| :--- | :--- |
| 饺子馅 | 葱姜水分三次加入，每次都要朝一个方向搅拌至吸收 |
| 饺子馅 | 葱花铺在肉馅上，热油趁热浇上去**激出香味** |
| 白菜素饺子 | 切好后加一圈食用油，**可以锁住水分，不容易出水** |
| 白菜素饺子 | 不要乱剁，**不仅容易出水，口感也不好** |
| 肉花卷 | 葱花里加点小苏打，**颜色更翠绿** |
| 肉花卷 | 不用发酵，**直接擀**（省掉一次发酵） |
| 鸡胸肉 | 腌好以后加淀粉，**这一步可以让鸡肉煎出来更加焦香** |
| 鸡胸肉 | 小火慢炒两分钟，**杏鲍菇受热会慢慢出汁，汁水被鸡肉吸收进去** |

规律：**一个具体动作 + 一句它为什么有效**。有的甚至带上做错会怎样（“乱剁容易出水”）。读者记住的是这个“为什么”，不是步骤本身。

新文章里，这是硬要求：步骤可以少，但每步都得答得出“这一步是为了什么”。

## 三、语言特征

- **第一人称、口语**：“我今天包了一锅”“我一般会”“跟着步骤来”。
- **口感词成串出现**，且具体：鲜嫩多汁、不腥不柴、焦香嫩滑、清爽开胃、香而不腻、汁水丰盈、口口爆汁。
- **技巧句点名**：“注意不要乱剁”“这一步很关键”“特别过瘾”。
- **短句、逗号串联，节奏快**，一句一停顿。
- **感叹号密度极高**（一篇十来个），波浪号“～”收尾。
- **用 ❤️ 做小标题装饰**，用 emoji 分隔段落。

**保留**：第一人称、口语、口感词具体、技巧句点名、短句节奏。
**调整**：感叹号减到两三处；不用 ❤️ 和 emoji 装饰（公众号排版另有样式）；不用“姐妹们”“家人们”这类称呼。

## 四、不可照搬

### 1. 全部家庭场景（本篇硬约束）

| 原句 | 出在哪 |
| :--- | :--- |
| 我家老爷子知道我们全家都爱吃，所以每年一到过节就张罗着包饺子，一家人围在一起 | 饺子馅 |
| 舅妈一时兴起，自告奋勇调了一大盆馅……孩子咬一口就放下了 | 饺子馅 |
| 家有上学娃，早餐既要简单省事 | 肉花卷 |
| 每次做俩娃都忍不住吃到撑 | 肉花卷 |
| 家里有孩子，我放的比较少 | 肉花卷 |
| 就连不吃蔬菜的娃也爱吃 | 白菜素饺子 |
| 有时间也给家人做上一盘 | 鸡胸肉 |

这些是例文的情绪来源，也正是新文章要去掉的部分。**开篇的由头、中段的口味说明、收尾的号召，三处都要重写。**

### 2. 配方与身份背书

“今天星妈就把从 30 年饺子馆学来的配方分享给大家”“饺子馆不外传的配方”——用户没提供来历就不写。这类句子读起来可信度很高，编一句整篇都跟着变假。

### 3. 用量与火候数字

例文中的“500 克普通面粉、3 克酵母、270 克清水”“大火蒸 12 分钟”“腌十分钟”“小火慢炒两分钟”，**只有用户给了才能写**。不能照着例文的数字填进新菜里——不同菜的用量不通用，读者照做失败，文章就废了。

### 4. 绝对化的效果承诺

“比外面饭店的饺子还好吃”“一周 8 次吃不够”“一口一个比肉饺子舒服”——**口味对比属于主观评价，可以保留类似的热度，但不要做可被证伪的横向比较**（“比 XX 家的好吃”“比饭店强”）。写自己的感受没问题：“这个做法我自己最常做。”

### 5. 健康功效

四篇都没写功效，这是对的。新文章同样不写“补钙”“养胃”“低脂不长肉”这类断言——那属于健康科普，改用 `yangsheng` skill 并按其核查要求办。

## 五、逐篇速览

| 篇目 | 开篇路子 | 可借鉴 | 要去掉 |
| :--- | :--- | :--- | :--- |
| 饺子馅不外传配方 | 俗语（形似元宝）+ 节日场面 | 步骤里的“为什么”写得最密；翻车对照（又干又柴）好用 | 老爷子、舅妈、孩子、“30 年饺子馆” |
| 早餐肉花卷 | 生活场景（上学娃的早餐） | 一次发酵的省事点讲得清楚；小苏打保绿这类小技巧 | 俩娃、孩子、吃撑 |
| 秋天白菜素饺子 | 俗语（好吃不过饺子）+ 时令 | 素馅不出水的处理、素饺子煮法（加一碗凉水） | 不吃蔬菜的娃、“提前纳入中秋菜单” |
| 鸡胸肉配杏鲍菇 | 反常识提醒（别只会水煮） | 开篇最利落的一篇；煎的火候和出汁原理讲得明白 | 姐妹们、“给家人做一盘” |

**综合结论**：骨架和语感照学，**开篇的由头、收尾的落点、以及所有涉及“谁吃”的句子自己重写**。
