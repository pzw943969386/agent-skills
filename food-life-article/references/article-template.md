# 美食生活文章动态模板

根据用户素材选择模块，不要求全部使用。生成成稿时删除所有说明和占位符。

## 1. 输入信息卡

写作前整理：

```text
任务类型：真实记录 / 创作样稿 / 纯菜谱 / 润色
餐次：早餐 / 午餐 / 晚餐 / 加餐 / 未指定
用餐人物：一人 / 两人 / 家庭 / 朋友
菜品：按实际数量记录
场景：用户提供的天气、季节、心情、事件；未提供时不擅自添加
平台：公众号 / 小红书 / 朋友圈 / 普通文章
篇幅：短 / 中 / 长
配图：有照片 / 需要占位 / 不需要
特殊要求：饮食限制、禁用词、账号结尾等
```

## 2. 生活随笔模板

```text
# [原创标题]

[真实场景或当天状态，2~4句。没有素材时从做饭动机或食材切入。]

[可选菜单句：今天吃的是……]

[可选：全桌合照占位]

## [菜品一]

[食材与预处理。]

[关键烹饪过程。按动作顺序写，加入一个真实状态变化。]

[味道和口感，1~2句。]

## [菜品二 / 汤 / 主食]

[按实际菜品数量重复菜品模块，不强行补足两道或三道。]

[回到整顿饭的具体感受。]

[从当餐细节自然生长出的生活感悟，1~2句；没有合适感悟时可以不写。]

[可选：原创祝福、互动问题或账号固定栏目。]
```

## 3. 短平台模板

```text
[一句有画面的开头]

今天吃：[菜品清单]

[菜品一：一个关键步骤 + 一个口感]
[菜品二：一个关键步骤 + 一个口感]
[按实际数量继续]

[一句具体收尾，不强行升华]
```

## 4. 纯菜谱模板

```text
# [菜名]

食材：[主料、辅料、调味料]

做法：
1. [预处理]
2. [烹饪步骤]
3. [熟成状态和出锅]

提示：
- [关键火候或防失败技巧]
- [必要的食品安全提醒]
```

## 5. 配图占位规则

仅在用户明确需要排版稿时插入：

```text
【配图：整桌成品】
【配图：菜品食材】
【配图：关键烹饪过程】
【配图：菜品成品】
```

不为每个步骤机械插图。已有照片时，根据照片内容决定位置。

## 6. 输出前清理

- 删除全部方括号说明、模板提示和空模块。
- 检查菜品数量是否与用户素材一致。
- 检查是否擅自添加天气、人物、经历或食材来源。
- 检查是否照搬参考标题、句子或固定签名。
- 检查肉类、蛋类、豆角和海鲜是否有充分加热提示。
- 仅在用户需要公众号系列稿时保留“往期回顾”等栏目。
