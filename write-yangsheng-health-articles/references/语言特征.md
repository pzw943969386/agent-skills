# 语言特征

从 7 篇历史原文提炼表达方式。**学亲近、连贯和结论前置，不照搬医学断言、作者身份或失当标点。**下列长度、数量和句式是风格偏好；准确、清楚和适合当前选题优先。

## 一、一段一个气口

原文常把“前提—转折—结果—补充”用逗号串起来，读起来像面对面讲解。可以保留这种连贯感，不必模仿长句和段末逗号。

- 一段通常讲清一件事，约 30—120 字，可按内容增减。
- 长短句交替。句子出现多层条件、多个结论时，拆开更清楚。
- 句意完整就用句号，并列项按需要用顿号或分号。
- 医学限制条件应贴着结论写，不要藏在下一段或文末。

示例：

> 先看研究比较了什么。两组人都改善了，不等于其中一种食物带来了额外好处，还要看两组之间有没有可靠差异。

## 二、金句可以独立成段

短句用于收住论点，不必每节都有。每篇可放 1—3 处，也可以不用；篇幅和信息量决定数量。

适合借鉴的表达示例：

- 吃了什么要看，替掉了什么也要看。
- 一项研究给了线索，不等于每个人都有同样结果。
- 数字要连着条件看。
- 馋的有时不是食材本身，而是那一口味道。

可以用对比、设问或生活化比喻，但不能为了有力而省掉决定结论的条件。不要把“某个症状就是某器官在求救”当成确定诊断，也不承诺坚持多久就能换来某种结果。

## 三、术语紧跟大白话

术语首次出现时给简短解释，后文用读者能理解的称呼。解释保持原意，不把复杂病理压缩成貌似直观、实际错误的一条因果链。

| 术语 | 可参考的解释方式 |
| :--- | :--- |
| 观察性研究 | 观察不同人群之间的差异，不能单靠它认定谁导致了谁 |
| 随机对照试验 | 通过随机分组比较不同安排的结果，还要看具体研究条件 |
| 对照组 | 用来比较的那一组，判断效果时不能只看干预组自身的变化 |
| 相对风险 | 与比较对象相比的风险大小，还要结合原本风险理解 |

通常按“读者的问题 → 必要术语或指标 → 证据能说明什么 → 生活中的含义”推进。不需要解释机制时可以省略；没有证据时不能补一个“听着合理”的机制。

## 四、设问推进

用设问换气，比机械的过渡词自然。设问本身也不能预设未被证实的结论。

- 这说明什么？
- 为什么是这个量？
- 那到底还能不能吃？
- 研究里比较的是哪些人？
- 是这组人有变化，还是它比对照组改善得更多？

## 五、结论先说，语气与证据匹配

开篇尽早回答核心问题，再解释依据和条件。明确不等于绝对，证据有限时也可以把话说清楚。

- 可以说：“这项研究不能支持这个说法。”
- 可以说：“目前还不能据此判断有没有额外好处。”
- 核实确实存在误读时，可以直接指出哪里读错了。
- 不为强化语气反复写“大错特错”“从根上就是错的”。
- 不把“没有证实有效”改写成“证实完全无效”，也不把“未发现组间差异”改写成“与它毫无关系”。

## 六、人称与场景

- **默认身份**：普通科普作者。可以直接写“你”“很多读者”“有些朋友”，不默认具备医生或营养师资格。
- **第一人称**：可以用于本次确实做过的工作，如“我核对了这项研究”。没有实际检索时，不写“我翻遍了研究”。
- **接诊、回信、患者群和后台留言**：只用用户提供的真实素材，不编造“门诊里有位患者”“后台好几个人问我”。身份和署名也由用户提供，不能沿用范文作者的名号。
- **假设场景**：可以写“比如，有人早餐习惯……”“假设你平时……”，让读者清楚这是举例。不要添加诊断、检查结果和对话，伪装成真实病例。
- **读者称呼**：亲近且尊重。涉及疾病时先准确说明适用人群，再按上下文使用简短称呼。

## 七、比喻要帮读者理解

比喻落在日常生活上，点到为止。例如：“一项研究像一块拼图，还要和其他证据放在一起看。”

不使用“清理血管”“给心脏踩刹车”等容易被理解成生理事实的表达来承载结论。引用真实传言时应标明归属并及时澄清。比喻不能代替机制证据，也不能暗示食物与药物疗效相同。

## 八、标点与用词

- 以中文规范标点为主，感叹号、破折号按需要少量使用，不设机械禁令。
- 引号可用于真实引文、术语或需要澄清的说法。引用必须准确，不虚构引语。
- 少用“综上所述”“在当今社会”“随着生活水平提高”等空泛套话。
- 不必强行玩梗，也不必为了口语感故意写错标点。
- 链接、单位、研究名和必要英文按原有规范保留。

## 九、时间与量词

- 研究年份、随访时长、干预量照核实后的来源写；不为显得专业而添数字。
- 区分研究观察时间和个人见效时间，不能把前者改写成后者。
- 具体用量说明对象及口径，如每天还是每次、可食部还是带壳重量；必要时交代烹调方式。
- 日常参照只帮助估量，不能伪装成精确换算。不同大小的“一把”“一汤匙”没有统一重量。
- 数字通常用阿拉伯数字；口语短语可用中文数词。

## 十、结尾提示

默认保留简短科普提示：

> 本文仅作健康科普，不能替代个体诊疗；身体不适请及时就医。

涉及用药时，根据内容补充：

> 不要根据本文自行停药或调整剂量，用药问题请咨询医生或药师。

免责声明不能补救错误建议。若正文涉及就医时机，应依据具体症状和可靠来源说明，不统一套用“先观察两周”。
