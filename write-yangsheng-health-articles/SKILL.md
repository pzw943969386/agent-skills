# 养生健康文章写作

把读者关心的健康问题讲清楚：先给证据支持的结论，再解释依据和适用条件，最后给出日常能做的事。学习参考文章的推进方式，不继承其未经核实的医学结论。

## 定位与默认约定

- **正文默认 800—1000 字。**围绕一个核心问题，优先保留最相关的证据、必要限制和行动建议。压缩篇幅时先删重复举例，不删研究前提或适用人群。用户明确指定其他篇幅或格式时，以当前要求为准。
- **一篇保持同一叙述身份。**默认用亲切的科普作者口吻。用户提供医生、营养师等真实作者身份时，可调整措辞；不自行声称职业资质，不虚构接诊、患者群、后台留言或个人经历。演示场景用“比如”“假设”标明；“我查阅了研究”只在实际查阅后使用。
- 如需署名，沿用用户提供的名字或账号名；无名字时可留 `XX聊养身` 占位，并在正文外说明，署名不暗示医疗资质。
- 不套用“出现这 N 种迹象，寿命可能长不了”等恐吓式症状预警模板。个人病情咨询不按公众号文章骨架处理。

## 写作前

1. 主题或标题已给就直接推进，不要求用户再选标题、确认提纲。信息足够时自行确定普通读者和科普用途；缺少主题时才问。用户标题含未经支持的断言时，保留话题并改成事实一致的标题，在正文外简要说明。
2. 写正文前读 [语言特征](references/语言特征.md) 和 [数据核查范例](references/数据核查范例.md)。生成或修改标题时读 [标题公式](references/标题公式.md)；需要结构示例时读 [范文拆解](references/范文拆解.md)。范文用于分析写法，不作为医学来源。
3. **先核证据，再确定结论和骨架。**研究效果回原论文，推荐量查官方指南，营养成分查权威成分数据库；同时核查无数字的机制和健康论断。新闻稿和二手科普只作检索线索。来源与结论的对应关系保留到文末，具体要求见数据核查参考。
4. 无法联网、全文不可访问或找不到出处时，不声称已核实，不用印象补数字或机制。可依据用户提供的原文或已核实资料缩小文章范围；无法支撑核心结论时，交代缺口并请求必要来源，或交付明确标为待核查的框架，不冒充可发布成稿。

## 正文骨架

按选题选择下列结构，允许合并、删节或调整顺序。各段预算是约数，合计约 900 字，含段内金句和过渡句，给小标题留出余量；最终以整篇计数为准。不为填满模板凑研究、凑变化或凑机制。

共同写法：

- 开篇约 2—4 句，接住具体疑问，给出有条件的结论。证据不足也是可以前置的结论。
- 用少量独立短段突出要点，金句不能省掉必要条件或把相关性说成因果。
- 小标题够用就行，可用“01 / 02 / 03”编号，标题后不加冒号。
- 结尾落到具体行动，可加一句自然的互动问句，并保留“本文仅做科普，身体有不适请及时就医。”

### 骨架 A：反常识辨析型

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 真实存在的说法或读者疑问，加证据支持的初步结论 |
| 说法怎么来的 | 150 | 指出概念混淆、比较对象或被省略的条件；没有可查谣言时直接解释疑问 |
| 研究到底说了什么 | 230 | 设计、人群、比较对象、结果和局限；可说明没有足够直接证据 |
| 为什么不能这样推 | 160 | 解释推理边界；机制有依据时才展开，区分人体发现与机制假说 |
| 日常该怎么做 | 200 | 与证据匹配的做法、适用人群和限制，有可靠依据时给量和频率 |
| 结尾 | 60 | 行动提醒、可选互动和免责声明 |

### 骨架 B：食材定量型

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 能不能吃、吃多少的具体疑问，加有条件的结论 |
| 先看食材和吃法 | 160 | 与问题有关的营养特点、加工方式和搭配，不堆指标 |
| 证据支持什么 | 240 | 1—3 条有依据的发现，可包括未发现差异；引用干预效果时交代比较组与背景饮食 |
| 哪些人要调整 | 150 | 与本题相关的适用人群、过敏或其他限制；不用同一个量覆盖所有读者 |
| 怎么吃、吃多少 | 190 | 有来源的推荐量、可行吃法和生活场景，注明是替代其他食物还是额外添加 |
| 结尾 | 60 | 行动提醒、可选互动和免责声明 |

只有研究确有相关观察期且有助于理解时，才解释时间窗口。研究随访“半年”不能写成“吃半年必有变化”，也不推定最佳食用频率。没有直接食材试验时，可依据指南解释日常搭配，不强行写疗效和对照组。

### 骨架 C：节气起居型

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 当季生活困扰，或明确标为假设的场景，加温和的回应 |
| 起居调整 | 200 | 结合当地气候、日照、年龄和生活安排讲作息，不把节气等同于统一睡醒时刻 |
| 饮食微调 | 180 | 选少量与本题有关的饮食建议，有可靠来源再给量 |
| 一个日常行动 | 220 | 与证据相符、适合目标读者的可执行做法；不要求每篇写穴位或自测 |
| 适用边界 | 140 | 谁需要个别调整；涉及症状时按具体问题核查就医建议，不统一要求观察两周 |
| 结尾 | 60 | 行动提醒、可选互动和免责声明 |

传统养生解释与现代临床证据分开表述。涉及穴位或按摩时，须核查依据、适用范围及禁忌，不许诺治疗疾病；无充分依据时省略。症状记录不能成为推迟必要就医的前提。

## 语言规矩

- **口语连贯，结论清楚。**允许逗号串联的长句，也允许短句换气；意思说完用句号，不机械模仿段末逗号。
- **术语紧跟大白话。**第一次出现解释清楚，后续可用简称；解释不能夸大或把复杂病因归成一个原因。
- **数字挂条件。**说明适用人群、单位、每次或每天、生熟及可食部口径等相关条件。生活化参照只作近似，不能把不同来源拼成一个“最佳方案”。
- 用“你”“不少人”“老朋友”等直接对话。“糖友”等称呼只在相应人群的文章中使用。
- 少用“综上所述”“值得注意的是”“首先其次最后”等套话。比喻贴近日常，但不代替证据。

## 事实边界

- **标题、正文、金句执行同一证据标准。**不虚构权威背书、研究、数字或谣言，不靠问号或“或许”包装无依据的断言。
- 不承诺疗效，不把食品写成药物替代品，不将单一食物与整套饮食干预的效果混为一谈。
- 引用组间效果时说明比较对象、干预条件和组间差异；不能只报一组前后变化。没有显著差异不等于证明完全无效，不能从花生试验写出“减重跟花生没关系”。
- 观察性结果按相关性表述；横断面还要说明时间顺序不明。数学模型、动物或体外实验须标明，不能写成人体临床疗效。机制的合理性不能证明真实食用量有益。
- 不建议自行停药、换药或改剂量；涉及用药可写“请遵医嘱用药，调整方案先咨询医生”，不用“一片都不能少”等绝对化口号。
- 不替读者诊断或开检查清单。确需提示就医时，依据具体问题和可靠来源给就医方向，由医生决定检查；免责声明不能弥补正文中的误导。

## 交付与计数

- **字数口径：**正文可见字符数，含标点、小标题、数字、英文字母和免责声明，每个字符计 1；不计空格、换行等空白。文章主标题、署名、文末来源和编辑说明不计入。Markdown 排版标记不算正文字符。
- 交稿前，把最终正文（含小标题）转成纯文本，单独保存为 UTF-8 文件，不含文章主标题、署名、来源或编辑说明，再运行：

  ```bash
  python scripts/count_body.py <正文纯文本文件>
  ```

  脚本相对本 skill 目录定位，只计数字符，不解析 Markdown 或猜测正文边界。先从最终排版稿提取可见文字，保留内容本身的标点。用户另定篇幅时可传 `--min-length` 和 `--max-length`。调整正文后重新计数。
- 默认交付一个标题和正文；用户需要时可另给 2—3 个备选标题。不加配图占位或抓取残留的“发布地点”，不虚构发布时间。
- 在正文之外附简短的“来源与核查说明”，为关键健康结论和数字提供直接支持它们的原论文、官方指南或成分数据库链接，并注明必要局限。排版服从使用环境的引用要求，不能为保持正文样式而省略必需的引用。
- 交付前检查：标题是否真实，人设和案例是否有来源，结论是否超出证据，数字是否带条件，行动是否适合目标读者，字数是否达标。未完成核心核查时明确标为待核查稿。
