# 普通人的钱、体面与生活

目标只有一个：写出来的文章，放进例文里读不出是另一个人写的。不是写得比例文“更好”“更精致”，而是写得和例文一样。

例文的作者是一个普通上班族，说话平实、句子完整、连接词多，讲自己和身边人的账，判断下得很满，最后告诉读者“这样就已经很不错了”。照这个人写，不要换成更有文采的作者。

## 第一步：完整读原文，不许跳过

每次动笔前，用 Read 完整读至少两篇原文：表格里对应的一篇，再加一篇其他题材的，避免只模仿一篇的情节。表格给了两篇时，可以两篇都读，再加一篇其他题材的。每篇只有一千三百字左右。不能只看拆解或本文件的摘要就动笔。用户指定了哪篇，以那篇为主。

## 声音：照例文的样子写

**句子写完整，连接词写出来。** 例文主谓宾齐全，因果和转折都明说：“并不是……而是……”“但是”“并且”“之后”“因此”“在……的时候”“那会儿”。一句话通常二十多个字。不要为了节奏把句子切成三五个字的碎句，不要一行一句地往下砸。

**说法实在，略偏书面，带一点转述感。** “我没有勇气接上话来”“随便问了一句”“手里拿着一杯茶，笑眯眯地没有搭话”“工资单看起来很美观，但是生活并没有改善很多”。偶尔出现不那么顺口的搭配是这套文风的一部分，例如“之后就开始吃我了”“真正的吃人者，并非车贷，而是后面的那串小钱”。但每句意思必须读得懂，不写错字、乱码、隐藏字符。

**不要文艺腔。** 不用精巧比喻、意象、镜头感描写（光线、雨、窗外、烟雾），不写“差七倍。”“那年我二十三。”这种单独成段的电影式停顿。例文的比喻都是大白话：“车是用来开的，并不是用来供奉的”“工资就是流水，养车就相当于用抽水机”。

**判断直接下，说满。** “大多数人的一生都达不到月薪两万元的程度”“别人看你的车是什么牌子的时间加起来不会超过三秒钟”“朋友圈里没有穷人，因为穷人不发朋友圈”。不补“当然也有例外”，不加“可能”“某种程度上”“在一定条件下”。

**每段人物或每一档，用一句判断收住。** 最常见的是“X并不是Y，而是Z”：“年薪并不是一个人的成绩单，而是一个家庭的账单。”“最难过的并不是因为收入低，而是说不出来‘不想再做了’这几个字。”

**账写成一段流水。** 逐项列金额，再给合计，再说相当于什么：“保险费700元、车位费2400元、每年保养两次共3600元……总共是三万六千元，刚好是我两个月的工资。”金额汉字和阿拉伯数字混用都可以，常带“元”“左右”“多”。

**人物用称谓，说大白话。** 老张、九哥、师兄、表嫂、包工头老徐、组里的一个小伙子、楼下五金店老板。每人一到三段：身份、一件事、一两句原话。原话可以糙：“过去人们尊敬的是车，而现在人们尊敬的是人自己。”

**段落短。** 一般一到三句一段，关键的话单独一段；讲一档人或一段经过时，可以写到四五句。

## 骨架

大部分例文是同一副骨架，默认照它写：

1. **开头两三句就进场景**：一句具体的问话或一个画面。买主问为什么卖车、搬家师傅猜办公室工资、同学聚会聊年薪、车库里蒙着车衣的车、发薪日晚了六天。
2. **“我”的反应**：没接话、说了假话、我没算过、在电脑前坐了很长时间。
3. **“我”当初怎么想、怎么做**，摊一笔账。
4. **账的后果**：具体放弃了什么。推掉滑雪说怕冷、生日只买三百多元的项链、给妈妈转了钱整月带饭、靠花呗还了一圈。
5. **两到三个对照人物**，每人代表一种情况，每人后面一句判断。
6. **回到“我”**：当年的自己并不笨／我也信过，后来才明白。
7. **结尾**：一串平实的生活条件，接“——这就已经很不错了”“——这样就很好了”“这样的车，才配得上你”。之后可以加一句评论区提问，如“你的车一年要花多少钱？评论区算一算。”（十篇里六篇这样收。）

题目不同时的变体（详见拆解）。问“等级／档次／什么水平”的题目，可以先按默认骨架写场景和账，再进入分档，最后回到开头的人：

- **分档篇**（七级月薪、男生月薪）：档位做小标题，写成纯文本单独一行，不加 `#` 也不加粗。两种格式选一种用到底：“第七级：3000元”，或者“一、3000元以下：贫穷的本质是没有选择”。每档两到五句，写这一档的生活动作或一个人。档位写完接两三节议论，结尾建议加互动。
- **编号论证篇**（年薪级别）：开头场景后用“一二三四”，每节加一个新条件（网上样本、家庭负担、时间代价、并不存在标准）。
- **段位篇**（买车段位）：每个人物代表一种认识，写完最后一句才给层次命名：“从行头，工具，账到人，就是男人买车的四个段位。”

## 标题

用户指定标题就用原题。自己拟时：一句连贯的短问句或一个完整名词短语，一口气读完。不用逗号、冒号、破折号、竖线、空格把标题断成两截，不加副标题，句末可以用问号。

用户认可的写法：“你的月薪能过上什么水平的生活”。可参考：“你的年薪属于什么级别”“男生买车的段位”“哪款车配得上你的月薪”“中国普通家庭的月收入等级”。避免“你的工资，养得起什么样的生活”这类先停顿再发问的标题，也不加“看哭了”“扎心了”。

标题问等级，正文就要有层次或者说清为什么没有标准；问配什么，就要给出判断办法。

## 素材与数据

- 例文全是第一人称，讲“我”和身边人的事。默认照这样写典型人物和经历，交付时在回复里用一句话说明人物和经历是虚构的典型情况。用户给了真实素材就用真实素材，不改其中的人物关系和立场。
- 不编造官方统计。要用国家统计局、城市中位数这类数据时，先查到可靠来源，写明年份；查不到就不用，改用身边人的工资来说明。数据只用一两个，不写成统计报告，正文里不加来源注释，来源放在回复里说明。
- 账要算对：合计等于分项之和，月和年不混用，日薪换月薪写出天数。例文里有几处账算错了，这一点不要学，算对不影响口吻。

## 执行与交付

1. 用户给题就写；没给题，从收入、存款、买车三组里选一个。多个独立主题分别成篇。
2. 完整读两篇原文和语感样本，按骨架动笔。
3. 写完做三项检查：
   - 按 [去AI自检](references/去AI自检.md) 逐项对照，重点是“读起来像不像同一个作者”。
   - 运行 `python3 scripts/style_stats.py <正文文件>`（Windows 上用 `python`），看连接词密度、平均句长、短句比例是否落在例文范围内。落在范围外就照语感样本改，不要为了凑指标硬塞词。
   - 按 [交付格式](references/交付格式.md) 计数。
4. 按 [API 检测与复测](references/AI检测.md) 调用朱雀检测，命中时修改复测，默认最多三轮修改。没有密钥或者用户要求跳过时，在回复里写明“未检测”和原因。
5. 默认 1100—1500 字，UTF-8 Markdown，存到本目录 `成稿/`。标题写在回复里，正文文件里不重复。用户对篇幅、格式、位置的要求优先。
6. 局部修改只改用户指的地方，不重做整篇。

最终回复给出标题、文件链接、检测结果，再用一句话说明哪些是虚构典型、哪些数据待核实。不附写作自评。
