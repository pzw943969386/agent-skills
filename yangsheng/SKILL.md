# 养生健康文章写作

把读者关心的健康问题讲清楚：先给证据支持的结论，再解释依据和适用条件，最后给出日常能做的事。学习参考文章的推进方式，不继承其未经核实的医学结论。

## 定位与默认约定

- **默认交付一个 `.html` 文件**，用户用浏览器打开后全选复制、粘贴进公众号编辑器即可发布。样式、标记和平台硬规则见 [公众号HTML排版](references/公众号HTML排版.md)。用户明确要纯文本时才给纯文本。
- **正文默认 800—1000 字。**围绕一个核心问题，优先保留最相关的证据、必要限制和行动建议。压缩篇幅时先删重复举例，不删研究前提或适用人群。用户明确指定其他篇幅或格式时，以当前要求为准。采用骨架 D（人群分层型）时篇幅通常到 1100—1400 字，见该节说明。
- **一篇保持同一叙述身份。**固定作者：**华姐，退休的养生爱好者，没有医疗执业资质**。这个身份决定了哪些场景能用，也决定了哪些话不能说。
  - 能用：留言里有人问、身边不少老朋友、我自己也这么吃、这些年看过不少说法。
  - 不能用：门诊里发现、我有个患者、接诊时、患者复查。**没有临床身份就一个字都不要往那个方向靠**，一句话穿帮，整篇的可信度跟着走。
  - 用户提供其他真实作者身份（医生、营养师、患者家属等）时，按用户说明调整可用场景；不自行升级资质。
- 署名用“华姐”。署名和正文都不暗示医疗资质，不虚构接诊、患者群、后台留言或个人经历。演示场景用“比如”“假设”标明；“我查阅了研究”只在实际查阅后使用。
- 不套用“出现这 N 种迹象，寿命可能长不了”等恐吓式症状预警模板。个人病情咨询不按公众号文章骨架处理。

## 写作前

1. 主题或标题已给就直接推进，不要求用户再选标题、确认提纲。信息足够时自行确定普通读者和科普用途；缺少主题时才问。用户标题含未经支持的断言时，保留话题并改成事实一致的标题，在正文外简要说明。
2. 写正文前读 [语言特征](references/语言特征.md) 和 [数据核查范例](references/数据核查范例.md)。生成或修改标题时读 [标题公式](references/标题公式.md)；需要结构示例时读 [范文拆解](references/范文拆解.md)。**出 HTML 稿前读 [公众号HTML排版](references/公众号HTML排版.md)**，按那里的标记体系和平台硬规则自检。范文用于分析写法，不作为医学来源。
3. **先核证据，再确定结论和骨架。**研究效果回原论文，推荐量查官方指南，营养成分查权威成分数据库；同时核查无数字的机制和健康论断。新闻稿和二手科普只作检索线索。来源与结论的对应关系保留到文末，具体要求见数据核查参考。
4. 无法联网、全文不可访问或找不到出处时，不声称已核实，不用印象补数字或机制。可依据用户提供的原文或已核实资料缩小文章范围；无法支撑核心结论时，交代缺口并请求必要来源，或交付明确标为待核查的框架，不冒充可发布成稿。

## 正文骨架

按选题选择下列结构，允许合并、删节或调整顺序。各段预算是约数，合计约 900 字，含段内金句和过渡句，给加粗重点留出余量；最终以整篇计数为准。不为填满模板凑研究、凑变化或凑机制。

共同写法：

- 开篇约 2—4 句，接住具体疑问，给出有条件的结论。证据不足也是可以前置的结论。
- **开篇可以先给处境，再给结论。**把一个被当成“个人选择”的行为还原成处境——加班到下午三点才吃第一口、忙起来顾不上、家里老人多年的老习惯——再摆出两边对立的说法，然后给有条件的结论。处境从读者真实的生活来，不写成编造的病例。两边都有说法时，可以明确写一句“今天不站队”，把作者的位置交代在前面，比假装中立更可信。
- 用少量独立短段突出要点，金句不能省掉必要条件或把相关性说成因果。
- **默认不写小标题，用加粗重点分段。**把一段里最要紧的判断加粗成一句，放在段首或段中，读者扫一眼就能接住这段在讲什么。加粗的是结论本身，不是“第一点”“原因有二”这类标签，也不编号、不加冒号。下面表格里的段落名（开篇、说法怎么来的）只是结构提示，不写进正文。
- **判断句小标题是可以的。**篇幅偏长、或段落之间是并列判断时（“相关不等于因果”“真正影响寿命的是节奏”），可以用一句结论充当小标题；用了小标题，就不在段内重复加粗同一句。编号式标签（“一、”“第一点”）仍然不写。
- **强调总量要有上限。**一篇里小标题、红色、下划线加起来不超过十处；到处都是强调，等于没有强调。三种标记各管什么、各放几处、具体样式怎么写，见 [公众号HTML排版](references/公众号HTML排版.md) 第一节。
- 结尾落到具体行动，可加一句自然的互动问句，并保留“本文仅做科普，身体有不适请及时就医。”行动之后可以再抬一层，收在长期习惯或读者自己的处境上；抬这一层不能挤掉免责声明。

### 骨架 A：反常识辨析型

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 读者所处的真实情境，或两边对立的说法，加证据支持的初步结论 |
| 说法怎么来的 | 150 | 指出概念混淆、比较对象或被省略的条件；可先把流传的说法说到最满（“铁证”“少吃一顿就是折寿”），再转折；没有可查谣言时直接解释疑问 |
| 研究到底说了什么 | 230 | 设计、人群、比较对象、结果和局限；可说明没有足够直接证据。讲证据缺口要给具体事实（“符合纳入标准的试验一项都没有”），而不是只说“证据不足”——这句缺口本身也要查得到出处 |
| 为什么不能这样推 | 160 | 解释推理边界；机制有依据时才展开，区分人体发现与机制假说 |
| 日常该怎么做 | 200 | 与证据匹配的做法、适用人群和限制，有可靠依据时给量和频率 |
| 结尾 | 60 | 从数据回到读者的长期习惯或处境，加行动提醒、可选互动和免责声明 |

### 骨架 B：食材定量型

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 能不能吃、吃多少的具体疑问，加有条件的结论 |
| 先看食材和吃法 | 160 | 与问题有关的营养特点、加工方式和搭配，不堆指标 |
| 证据支持什么 | 240 | 1—3 条有依据的发现，可包括未发现差异；引用干预效果时交代比较组与背景饮食 |
| 哪些人要调整 | 150 | 与本题相关的适用人群、过敏或其他限制；不用同一个量覆盖所有读者 |
| 怎么吃、吃多少 | 190 | 有来源的推荐量、可行吃法和生活场景，注明是替代其他食物还是额外添加 |
| 结尾 | 60 | 行动提醒、可选互动和免责声明 |

只有研究确有相关观察期且有助于理解时，才解释时间窗口。研究随访“半年”不能写成“吃半年必有变化”，也不推定最佳食用频率。没有直接食材试验时，可依据指南解释日常搭配，不强行写疗效和对照组。

### 骨架 C：节气起居型

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 当季生活困扰，或明确标为假设的场景，加温和的回应 |
| 起居调整 | 200 | 结合当地气候、日照、年龄和生活安排讲作息，不把节气等同于统一睡醒时刻 |
| 饮食微调 | 180 | 选少量与本题有关的饮食建议，有可靠来源再给量 |
| 一个日常行动 | 220 | 与证据相符、适合目标读者的可执行做法；不要求每篇写穴位或自测 |
| 适用边界 | 140 | 谁需要个别调整；涉及症状时按具体问题核查就医建议，不统一要求观察两周 |
| 结尾 | 60 | 行动提醒、可选互动和免责声明 |

传统养生解释与现代临床证据分开表述。涉及穴位或按摩时，须核查依据、适用范围及禁忌，不许诺治疗疾病；无充分依据时省略。症状记录不能成为推迟必要就医的前提。

### 骨架 D：人群分层型

适合“同一个食物，不同的人答案不一样”的选题。把“你是谁”提到台面上：先做一个关键区分，再按人群分层，每层给只属于这层的结论。

| 段落 | 参考字数 | 内容 |
| :--- | :--- | :--- |
| 开篇 | 100 | 具体疑问（真实留言，或明确标为假设的提问），加“对在哪、错在哪”的分层结论 |
| 一个关键区分 | 220 | 把主题拆成两类或几类（品种、加工方式、生熟），每类给证据和数值 |
| 人群分层 | 450 | 3—4 类人，每类 100—120 字：这类人的处境、最容易踩的坑、只属于这类的量和做法 |
| 加工或场景陷阱 | 180 | 常被当成同一类、其实不同的东西（如玉米糊和玉米棒），给证据 |
| 收束 | 120 | 按人群各收一句，落到“先问你是谁”的行动句和免责声明 |

要点：

- **分层要有依据。**分层维度取自证据或指南里真实存在的适用差异（是否确诊糖尿病、年龄与咀嚼吞咽能力、用药情况），不为凑段数切分。分不出真实差异时改用其他骨架。
- **每层的量和结论单独给。**不让所有层共用一句“适量吃”，也不把某一层的限制写成所有人的限制。替换关系要说明白：替掉了什么，才叫替代；照吃又照盛，那是加餐。
- **分层标签用能判断的说法**，如“血糖偏高但还没到糖尿病的人”“牙口不好、消化弱的人”；不用无法核实的体质分类替代可判断的人群特征。
- **个案素材按作者身份取舍。**按“定位与默认约定”里的可用场景写（留言提问、身边老朋友），不写门诊和患者。具体到个人的指标数值（如“血糖从 6.1 爬到 6.8”）只在用户提供真实素材时使用；否则改成不点名的普遍现象（“血压药吃着，血糖却慢慢往上走”），或明确标为假设场景。

## 语言规矩

- **口语连贯，结论清楚。**允许逗号串联的长句，也允许短句换气；意思说完用句号，不机械模仿段末逗号。
- **段落要短，长短交替。**一段讲清一件事，通常 30—80 字，**超过 100 字就拆**。长段（交代证据和条件）后面跟一个短段（把判断收住），长短句也交替。一整段全是长句、或者一段几百字，是这类稿子最容易犯的毛病；反过来通篇短句又像喊口号。交稿前数一遍各段字数。
- **术语紧跟大白话。**第一次出现解释清楚，后续可用简称；解释不能夸大或把复杂病因归成一个原因。
- **数字挂条件。**说明适用人群、单位、每次或每天、生熟及可食部口径等相关条件。生活化参照只作近似，不能把不同来源拼成一个“最佳方案”。
- **效应量后面接一句人话。**给出风险比或百分比之后，用一句话说明它在人的尺度上意味着什么。可以说“数字看着不大，放到人群层面就不是小数点后的差别”，也可以说“这个量级小到日常很难感知”。不能凭空换算成具体的死亡人数、寿命年数或“多少条生命”。把效应量翻译成人话，前提是条件已经交代清楚。
- **给现象起名字，但别让名字替机制背书。**把常被混在一起的状态分开命名（“没空吃”不是“轻断食”），读者一下就懂。名字不能读成已经证实的生理过程：“饥荒模式”“清理血管”这类说法要么标明是比方，要么不用。
- **用“不是 A，是 B”把读者认错的变量换回来。**“这不是轻断食，这是没空吃”“问题不在于吃几顿，而在于你少吃的那顿饭”“进食频率是框架，食物质量才是内容”——一篇两到四处，各管一段，B 那一半要有正文撑。
- **先站在读者这一边。**开篇和转折处替读者开脱（“可能根本不是你自己的选择”）或替读者说出困惑（“你越听越不知道该信谁”），再往下拆。引用研究时可以贴一个态度标签（“常被解读为铁证”“一个有意思的参考值”），标签只表态度不表结论。
- 用“你”“不少人”“老朋友”等直接对话。“糖友”等称呼只在相应人群的文章中使用。
- 少用“综上所述”“值得注意的是”“首先其次最后”等套话。比喻贴近日常，但不代替证据。

## 事实边界

- **标题、小标题、正文、金句执行同一证据标准。**小标题写成断言时标准不降——“关联确实存在”这种话，正文必须撑得住；撑不住就加条件或降级成疑问句。不虚构权威背书、研究、数字或谣言，不靠问号或“或许”包装无依据的断言。
- **会议摘要、预印本和未发表报告要标明身份。**只出现在学术会议摘要里的结果，不能当同行评议结论用。同一批数据的摘要数字和正式论文经常对不上（见 `范文拆解.md` 第 10 篇：8 小时进食窗的同一份数据，摘要里是 91%，正式论文里是 30% 出头）。这类材料可以提，但要在文中写清“这只是会议摘要，尚未正式发表”，且不能用它承载核心结论。找不到正式论文时按待核查处理。
- 不承诺疗效，不把食品写成药物替代品，不将单一食物与整套饮食干预的效果混为一谈。
- 引用组间效果时说明比较对象、干预条件和组间差异；不能只报一组前后变化。没有显著差异不等于证明完全无效，不能从花生试验写出“减重跟花生没关系”。
- 观察性结果按相关性表述；横断面还要说明时间顺序不明。数学模型、动物或体外实验须标明，不能写成人体临床疗效。机制的合理性不能证明真实食用量有益。
- **机制段要答得出三个问题：什么物种、什么剂量、怎么给进去的。**小鼠、大鼠、细胞还是人；喂食掺入、灌胃、注射还是外涂；那个剂量折成人要吃多少。写成“研究发现某成分能……”而不说物种和给药方式，读者就会当成人体结论——机制段是这类文章最容易失控的地方，见 `范文拆解.md` 第 9 篇。答不上来的不要写。
- **药物相互作用单独定级，不跟机制混着写。**动物或体外看到某成分影响药物代谢酶，不等于人吃这种食物会影响药效。人体证据与动物证据冲突时写人体那一侧，并交代浓度或剂量口径。涉及正在服药的读者，不写“可能影响药效”“擅自大量吃可能……”这类既缺人体证据、又足以改变用药行为的句子；确需提醒时只写“用药问题请咨询医生或药师”，不据此建议增减某种食物。
- 不建议自行停药、换药或改剂量；涉及用药可写“请遵医嘱用药，调整方案先咨询医生”，不用“一片都不能少”等绝对化口号。
- 不替读者诊断或开检查清单。确需提示就医时，依据具体问题和可靠来源给就医方向，由医生决定检查；免责声明不能弥补正文中的误导。

## 交付与计数

- **默认交付一个 `.html` 文件。**正文含标记和免责声明，用户用浏览器打开后全选复制即可粘贴发布；文件顶部写一行复制方法注释。文章主标题不写进 HTML——公众号标题是编辑器里单独的输入框，粘贴不会带过去，标题在回复里给。纯文本正文只在用户明确要求时另给。样式、标记体系与平台硬规则见 [公众号HTML排版](references/公众号HTML排版.md)。
- **字数口径：**正文可见字符数，含标点、数字、英文字母和免责声明，每个字符计 1；不计空格、换行等空白。HTML 标签与属性、Markdown 的 `**` 等排版标记都不计入。文章主标题、署名、文末来源和编辑说明不计入。
- 交稿前，把 HTML 剥掉标签后的可见文字存成 UTF-8 纯文本（不含主标题、署名、来源、编辑说明和 HTML 注释），再运行：

  ```bash
  python scripts/count_body.py <正文纯文本文件>
  ```

  脚本相对本 skill 目录定位，只计数字符，不解析 Markdown 或猜测正文边界。用户另定篇幅时，或写骨架 D（人群分层型，1100—1400 字）时，传 `--min-length` 和 `--max-length`。调整正文后重新计数。
