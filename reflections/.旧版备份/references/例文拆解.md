# 例文地图与写法拆解

当前目录十份例文，其中两份存款文主体近重复；不能把重复版本当成两次独立的风格证据。本文按写作功能组织，写作时只读相关部分及对应原文。

## 一、题材与标题的共同点

月薪、年薪、全家收入、存款、买车反复出现。它们易于比较，又连着读者的面子、责任和安全感。表面问题是“我在哪一档”“我配得上什么”，正文逐渐引入外部评价看不见的负担和代价。

标题多数很短，直接点出对象，用“你的”“男生”“普通家庭”圈定读者，用“等级”“段位”“配得上”制造自我对照。文章可以给出层次，也可以改变层次的含义。它们并不都承诺一份真实统计排名。

因此，只有共鸣情绪的长标题、只有生活难处的泛感悟、只有算法的实用教程，都不足以代表这套例文。相近题材也要换核心问题：存款可以写能撑多久，也可以写谁在依赖这笔钱；不要把同一篇37天故事换几个数字再写一遍。

## 二、收入：从找位置到重新理解位置

### 《男生月薪的几个档次》

[原文](../例文/男生月薪的几个档次.txt)。争论引入 → 作者原有想法 → 八档人物 → 回看比较。人物承担不同的处境：实习生不敢走、店长卖时间、设计师被亲戚评价、家庭支出占满工资、运营担心被替换、经营者自己承担损失。

有效的是每档在增加信息。不是每档都有引语，也不都止于引语；有些判断先写在标题里，有些藏在账单里。分组让读者感觉走到另一层，不是要所有文章都写八档三组。

### 《七级月薪，七种活法》

[原文](../例文/七级月薪，七种活法.txt)。直接列档，不铺故事。加不加蛋、要不要买、是否只选最低价，是收入对应的动作。再接住读者看完的反应，讨论时间与生活，最后给建议和互动。

它证明了素材少也可以写得可感。每档要有不同的生活变化，不能只是“更宽裕”。建议与互动是本篇的收法，不是所有文章的必填项。

### 《中国普通家庭的月收入等级》

[原文](../例文/中国普通家庭的月收入等级.txt)。搬家师傅对办公室工资的猜测，把“大家误判别人的收入”落到一句话。作者承认自己也信过高薪叙事，尝试用公开数据校准，再从高往低写收入处境。

倒序的作用是把目光从高薪拉回更多普通岗位。两万写时间代价，一万写开支随收入增加，五千写职业劳动与收入并不等价。最后的肯定来自前面的现实对照，而不是直接宣布“你已经很好了”。

数据在这里承担校准想象的作用，并不等于例文数据已核实。尤其标题是家庭收入，正文主要举个人工资，仿写必须修正这种错位。

### 《你的月薪达到城市中位数了吗》

[原文](../例文/你的月薪达到城市中位数了吗.txt)。母亲对收入的误解 → 作者被网络比较打击 → 身边劳动者 → 统计概念 → 城市与老家的评价差异。比较对象不断变化，同一数字被重新理解。

“差七倍”“那年我二十三”形成信息后的停顿；地铁里反复解释、挂电话后愣住，让情绪有动作。“哪个才是真的”提问，后文才有继续找答案的动力。结尾肯定已写清的生活承担。

### 《你的年薪属于什么级别》

[原文](../例文/你的年薪属于什么级别.txt)。酒桌上的轻描淡写与招聘时的材料冲突，作者暂不接话，留出往下读的理由。编号四节是论证层次：可见样本、家庭负担、时间代价、生活标准，并非四档薪资。

用一组对照解释一个新条件，判断可以直接。结尾低薪同事的晚饭是前文的回扣，不能据此推成高薪者都羡慕低薪生活。

## 三、存款：等级被重新定义为能做什么

[你的存款达到多少级了](../例文/你的存款达到多少级了.txt) 与 [你的存款到什么等级了](../例文/你的存款到什么等级了.txt) 共享发薪延迟、37天、母亲转账、车门贴纸、带父母出游等主体；主要区别是标题和部分展示文字、列表。

账先以事件出现：发薪日与还款日错开，查余额，得出37天。数字制造停顿后，穿插家庭关系与消费取舍，再把金额折成能支撑多久，最后写攒钱后真的做了什么。

分档很短，故事不平均分给每级。情绪次序是慌张、难堪、重新认识、踏实。算法帮助理解情绪，却不是文章全部。只留下“余额减预留再除月开支”，会丢掉人与钱的关系。

“敢”把抽象余地变成行动，是可迁移的写法；不要重复“敢生病、敢辞职”就当作新文章，也不能把某个存款数当作医疗或失业保障的承诺。

## 四、车：从价格与面子写到使用和自主

### 《你的工资该配什么车》

[原文](../例文/你的工资该配什么车.txt)。观点先行 → 当初只看月供 → 摊开持续成本 → 家庭急用时拿不出钱 → 一个算法与替代出行 → 回到车的用途。

账单后跟代价，读者才知道为什么要算。不是列完支出就连续讲几百字规则。先说只看工资不够，后面也不该又用工资直接决定车价。

### 《哪款车配得上你的月薪》

[原文](../例文/哪款车配得上你的月薪.txt)。邻居的车长期停放引起疑问 → 回想自己的购车与账目 → 放弃活动、自己带饭等后果 → 相亲后买车的同事 → 邻居与作者的后续选择 → 家庭需要时能付钱。

人物有前后照应：邻居不是开头用完就丢掉的道具。提车时短暂被关注，与此后自己持续付费形成落差。钱的意义由“别人看见什么”转到“遇事能做什么”。

可学闭合的叙事与具体机会成本，不复制卖车、家人生病、租车的整套情节。末尾20%之类经验比例不应升格成普遍财务规则。

### 《男生买车的段位》

[原文](../例文/男生买车的段位.txt)。先写卖车时的问答，再倒叙曾把车当作跑业务的底气以及承担的代价。五金店老板的皮卡强调使用，医生师兄的旧车强调支出取舍，包工头换车后仍有人找他做事，强调个人能力与信任。

四种认识到最后才命名为“行头、工具、账、人”。这是观念上的层次，不是车价从低到高。不同人物各完成一次推进，读者跟着作者理解，而不是先读四个概念定义。

结尾不羞辱当初贷款买车的自己，承认年轻时想被尊重的愿望，再重新说明体面。这里的自我谅解，让转变有温度；不能写成作者从头到尾比所有人都清醒。

## 五、事实和文字问题：仿写前避开

下表是原文内部检查与待核实项，不代表已做外部数据核验。未受托修改例文时保留原文件。

| 原文 | 需要注意 |
| --- | --- |
| 男生月薪 | “3000以下”放入3500样例，前两档重叠；无收入与负债是不同维度；负债必然导致工资卡不能使用不可照搬。 |
| 七级月薪 | 高薪者受工作约束，与收入越高时间掌控越强的说法存在张力；分档生活水平取决于城市与家庭条件。 |
| 家庭月收入 | 家庭总收入、个人工资、居民人均可支配收入混用；最高收入组“860元”与后句“不到九千”不能相互印证；最高组均值不能当作进入前20%的门槛；2025年所引金额、年份与出处需重新核实。日薪到月薪交代天数，不能把职位样例推出“大多数人一生达不到”。 |
| 两篇存款 | 母亲转账方向含混；“想做的事说不”等语义错位；“三个月敢生病”等是修辞，不能作为支出覆盖结论。 |
| 月薪中位数 | 九人5000、一人500000，平均54500；40单×5元×30天为6000，七八千需补条件；广州7500缺年份样本；中位数不等于读者本人位置；母亲对不同金额的态度不能概括成“同一份工资”。 |
| 年薪级别 | 月薪10000到15000，全年多60000，近五万需说明口径；十来万与五十余万不是同样年薪；个别招聘样本不能代表全国。 |
| 工资配车 | 学费三千与卖车亏三万未统一；月供不是一次性费用；3800+600+1500+500已为6400；“算全年，除十二”不是五个汉字。 |
| 哪款车配月薪 | 月供2200与年养车费用需分别算；两万元约占8.4万元的24%，不是精确的五分之一；已列保险、两处停车、燃油后，年两万元估计需核算；“2200是一顿饭钱”等细节与设定收入不协调。 |
| 买车段位 | 保险、停车等月年单位不明，无法直接复核3.6万元合计；提前还五万节省多少利息依赖贷款条件；折旧也不能给车型无关的确定比例；买卖主体、问话和“球队”等有文字错位。 |

不要因为要保留锋芒就复制统计错误，也不要因为要修正错误就把全部判断改成含糊的免责话。让主张针对材料能支持的范围。
